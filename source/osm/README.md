# OpenStreetMap data

The files in `cache/` are Overpass API extracts of OpenStreetMap data, fetched by
`source/osm_fetch.py` in October 2026 (each file's `osm3s.timestamp_osm_base` gives the exact date).
Each is named after the SHA-1 of its query in `osm_fetch.py`.
